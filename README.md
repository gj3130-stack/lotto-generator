# 🎰 LOTTO VIP MASTER PRO (v2.5)
> **최고급 상업용 빅데이터 AI 로또 6/45 종합 분석 및 프리미엄 조합 솔루션**

---

## 💎 솔루션 개요 (Overview)
**LOTTO VIP MASTER**는 상용 소프트웨어 판매 및 구독형(SaaS/Freemium) 서비스를 목적으로 기획·개발된 최고급 로또 6/45 플랫폼입니다.
옵시디언 블랙 & 샴페인 골드 글래스모피즘 기반의 VIP 럭셔리 디자인과 브라우저 무음원 Web Audio API 사운드 신시사이저, 빅데이터 분석 엔진, 실물 종이 영수증 티켓 생성기, 그리고 한국인 맞춤형 킬러 콘텐츠(꿈 해몽, 사주 럭키 넘버, 실수령액 계산기)를 완벽하게 탑재하고 있습니다.

## ✨ 핵심 기능 (Features)

### 1. 🎰 번호 생성 (Smart Generator)
- **1~5게임 일괄 추출**: 원하는 게임 수(1~5게임)를 원클릭으로 동시 생성
- **5대 프리미엄 조합 엔진**:
  1. **균형형 (Balanced)**: 역대 당첨 통계 최적 구간(합계 100~175, 홀짝 비율 2:4~4:2, 연속번호 3개 이상 방지) 자동 필터링
  2. **빈도형 (Hot Picker)**: 역대 1회부터 최신 회차까지 최다 출현 번호 가중치 부여
  3. **미출현형 (Cold Picker)**: 최근 15회차 이상 출현하지 않은 장기 휴면 번호 확률적 반등 노림수
  4. **혼합형 (Smart Hybrid)**: Hot 3개 + Cold 2개 + 황금 난수 1개 최적 배합
  5. **완전 랜덤 (True Random)**: 암호학적 난수(`crypto.getRandomValues`) 기반 100% 독립 무작위 추첨
- **⭐ 번호 LOCK (고정수)**: 1~5개 번호를 고정하고 나머지만 조합
- **🚫 제외 번호 (필터링)**: 원치 않는 번호 최대 39개 원천 배제

### 2. 📸 종이 영수증 티켓 생성 & 이미지 SNS 공유 (바이럴 무기)
- 실제 오프라인 복권방 슬립지 감성의 종이 영수증 카드 렌더링
- `html2canvas` 기반 고화질 PNG 이미지 원클릭 다운로드
- 카카오톡 / 인스타그램 스토리 공유 텍스트 포맷 지원

### 3. 📊 빅데이터 통계 대시보드 (Big Data Dashboard)
- 역대 1회부터 누적 출현 빈도 TOP 10 랭킹 차트
- 최근 급상승(Hot) 번호 및 장기 미출현(Cold) 번호 분류
- 홀짝(Odd:Even) 분포 비율 분석
- 6개 번호 총합 구간별 정규분포 통계

### 4. 🔍 1~45번 번호별 인텔리전스 탐색기 (Deep Explorer)
- 1~45번 번호 클릭 시 누적 출현 횟수 및 전국 랭킹 즉시 표시
- 해당 번호와 가장 자주 함께 당첨된 **찰떡궁합 단짝 번호** 추천
- 최근 10회차 출현 이력 상세 조회

### 5. 🧪 조합 진단기 (Simulator)
- 사용자가 선택한 6개 번호의 100점 만점 밸런스 지수 채점
- 총합, 홀짝, 고저 비율, 5색 구간 분포 정밀 진단
- 최근 회차 대상 가상 당첨 시뮬레이션(1~5등 적중 횟수)

### 6. 💾 마이 보관함 & 실제 당첨 자동 대조
- 생성한 조합 로컬 브라우저 영구 보관 (오프라인 지원)
- 최신 실제 당첨 회차 번호와 1초 만에 자동 비교 대조
- 맞춘 번호 황금빛 하이라이트 및 등수(1~5등, 낙첨) 판정

### 7. 🎉 잭팟 당첨 연출 (Celebration)
- 1등~3등 당첨 시 화면 전체 골드 컨페티 폭죽 효과
- Web Audio API 기반 팡파레 잭팟 사운드 효과

### 8. 💤 한국인 특화 킬러 콘텐츠 (Dream & Saju)
- **전통 꿈 해몽 횡재수 사전**: 돼지, 똥, 조상님, 불, 용 등 검색 시 번호 추천
- **오늘의 사주 럭키 넘버**: 생년월일과 오늘 날짜의 천간지지 일주 분석 번호 추출

### 9. 💸 1등 당첨금 실수령액 & 플렉스 계산기 (Dopamine Trigger)
- 대한민국 세법(3억 이하 22%, 3억 초과 33%) 정밀 적용
- 당첨금에 따른 실제 통장 입금액 및 세금 공제액 산출
- 은행 예금 시 "매월 숨만 쉬어도 통장에 들어오는 세후 이자" 계산
- 포르쉐 911, 치킨, 아파트 등 구매 가능 수량 시각화

### 10. 🗺️ 전국 1등 명당 지도
- 노원구 스파, 부산 부일카서비스 등 전국 1등 최다 배출점 리스트
- 네이버 지도 바로가기 연동

### 11. ⚠️ 책임 이용 및 건전 복권 문화 안내
- 매 회차 독립 확률 고지 및 100% 당첨 보장 없음 면책 조항
- 한국도박문제예방치유원 헬프라인(1336) 안내 모달

### 12. 💎 상업용 수익화(Monetization) 모듈

## 🚀 실행 및 빌드 방법 (Getting Started)

### 개발 서버 실행
```bash
npm install
npm run dev
```
브라우저에서 `http://localhost:5174/` 로 접속합니다.

### 프로덕션 빌드
```bash
npm run build
```
`dist/` 폴더에 최적화된 정적 웹앱 파일이 생성되며, Vercel, Netlify, Cloudflare Pages, AWS S3 등에 즉시 무료 호스팅 가능합니다.
